# DEADNET screenshots

36 real browser captures of the packaged game, at desktop 1600×1000 and phone 390×844. No generated mockups or image composites.

Presentation-only checkpoints use authored dialogue; screenshots 19/05 of Nora’s signal are staged story writing, not provider-inference evidence. Technical/debug badges are hidden in these press images only. The shipped app still identifies its response mode. No API calls, traces or measurements were fabricated. The ending is the actual authored game state, reached through the report action from a prepared checkpoint.

Images 21/22 contain solution/ending spoilers. [Manifest](manifest.json) records every scene.
